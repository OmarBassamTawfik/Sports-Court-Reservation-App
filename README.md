# Sports Court Reservation App

A web application for booking and managing sports court reservations.

## Features

- Search and browse available sports courts
- Book court time slots
- Manage your reservations
- View court availability

## Tech Stack

- **Frontend**: Flutter (Dart)
- **Backend**: Python
- **Platforms**: Web, Mobile (iOS/Android), Desktop (Windows, macOS, Linux)

## Quick Start

### Clone the repository
```bash
git clone https://github.com/OmarBassamTawfik/Sports-Court-Reservation-App.git
cd Sports-Court-Reservation-App
```

### Run the web app
```bash
cd Front_End
flutter pub get
flutter run -d web
```

### Run the backend
```bash
cd Back_End
pip install -r requirements.txt
python app.py
```
